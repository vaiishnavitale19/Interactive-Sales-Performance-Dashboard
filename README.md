# Interactive-Sales-Performance-Dashboard

## Project Overview
This project is an interactive Sales Performance Dashboard developed using Microsoft Excel. It transforms raw sales data into meaningful visual insights and helps analyze regional sales performance, sales executive achievements, and target performance.

The dashboard uses interactive region slicers, PivotTables, and charts to make data analysis simple and effective.

## Dashboard Features

- **Interactive Region Slicers:** Filter the dashboard by Chennai, Delhi, Mumbai, Nagpur, Patna, Pune, Ranchi, and Surat.
- **Raw Sales Data:** Source data used for analysis and dashboard creation.
- **Sales Performance Analysis:** Compare total sales across different sales executives.
- **Target Achievement:** Analyze the percentage of sales targets achieved.
- **Performance Gap Analysis:** Monitor how far sales executives are from their targets.
- **Interactive Visualizations:** Bar chart, pie chart, and line chart for clear data presentation.
- **VBA Automation:** Excel macros for automating selected slicer and PivotTable interactions.

## Tools and Technologies

- Microsoft Excel
- PivotTables
- PivotCharts and Charts
- Interactive Slicers
- Excel VBA
- Data Analysis and Visualization

## Project Workflow

1. Prepare the raw sales dataset.
2. Organize and summarize data using PivotTables.
3. Create charts to visualize sales and target performance.
4. Add region slicers for interactive filtering.
5. Arrange the charts and summaries into a dashboard.
6. Use VBA macros to automate selected dashboard actions.
